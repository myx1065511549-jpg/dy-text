# 抖音直播看板 · 使用说明

面向品牌自播直播间的弹幕舆情与实时氛围监控。给 VOC 分析和管理人员用。

---

## 一、怎么启动

1. 解压收到的 `douyin-dashboard` 整个文件夹（**别只拷 exe，同目录的文件都要**）
2. 双击 `douyin-dashboard.exe`
3. 稍等十几秒（首次启动要解压内置浏览器，慢一点正常），会自动打开看板页面，程序在后台运行，不显示黑色命令行窗口
4. 没自动打开的话，浏览器手动访问 **http://127.0.0.1:8848**

需要停止采集时，点击看板顶部的「停止采集」并确认。看板页面打不开时，也可以双击同目录的 `停止看板.vbs`。只关闭浏览器页面不会停止后台采集。

## 二、看板怎么用

**换直播间**：顶部输入框填直播间号（就是 `live.douyin.com/` 后面那串数字），点切换。切换后旧数据自动归档，不会丢。

顶部房间号旁会显示该直播间的账号名；切换直播间后会自动更新。

**各区块**：
- **直播节奏**（左上）：在线人数/弹幕量/进场量随时间变化。鼠标悬停看具体数值，**点曲线可回看那一分钟的弹幕**
- **商品讲解**（左）：本场全部商品，正在讲的会红色高亮标「讲解中」，显示讲了多久、期间多少弹幕、观众问了哪几类问题。**点商品看该商品讲解期间的全部弹幕**
- **VOC 问题弹幕队列**（左）：观众提问按 10 类自动归类（尺码型号/颜色款式/赠品配件/使用场景/发货售后/链接下单/价格优惠/质量效果/库存补货/风险负面）。**风险负面标红置顶**，是最该盯的。点分类看具体弹幕。齿轮按钮可自己改关键词
- **发言观众画像**（左下）：粉丝团占比、等级分布、性别
- **实时弹幕流**（中）：可按「粉丝团/路人」筛选
- **发言榜 / 屏蔽池**（右上）：点用户看他的全部发言；可屏蔽刷屏账号
- **热词榜**（右下）：点词看每次出现

**新场次**：点顶部「新场次」手动开一场（比如上下午分开统计）。旧场数据归档保留，「历史场次」里能看汇总、能删。

## 三、导出数据做分析

点顶部**「导出」**下载 CSV（Excel 双击直接打开，中文不乱码）。「历史场次」弹层里每场也能单独导出。

导出的是**分析宽表**，每条弹幕都带齐上下文：

| 列 | 说明 |
|---|---|
| created_at / date / hour / minute | 时间（**分析只用这个**） |
| content / content_len | 弹幕内容 |
| voc_categories / is_risk | 命中的问题分类、是否风险 |
| product_title / product_price_yuan | **当时主播在讲哪个商品、多少钱** |
| online_count | **当时多少人在线** |
| user_id / nickname / level / fans_level / gender | 用户信息 |
| is_blocked_word | 是否是刷屏（默认已剔除） |

导出已自动做好：锁单一数据源防重复计数、去重、剔除商家机器人刷屏。

## 四、商品功能需要登录（可选）

不登录也能用：弹幕、进场、在线、VOC、热词、画像全部正常。

**只有「商品讲解」这块需要登录抖音**（要拿商品名和价格）。未登录时点击商品面板的「登录抖音」按钮，在新打开的专用窗口中完成登录。程序会自动保存登录态并重新连接商品采集，不需要再运行目录中的脚本。登录后：正在讲哪个商品、每个商品讲多久、讲解期间观众问什么，才会有数据。

登录方式见随附的登录脚本说明；登录信息只存在你自己电脑上。

> ⚠️ **登录后请勿把整个文件夹再转发给别人** —— 登录信息文件（`auth_state.local.json`）会跟着走，等于把你的抖音账号给了对方。要转发请先删掉这个文件。

## 五、数据存在哪

全部在本地，就是程序目录下的 `danmu.db` 一个文件。**不上传任何服务器**。看板只监听本机 127.0.0.1，别人访问不到。

数据会一直累积（进场记录最占地方）。占用太大时，在「历史场次」里删掉不需要的旧场次即可。

## 六、常见问题

**打开是空的 / 没数据？**
直播间没在播，或刚启动还没连上（主源约 11 秒热身、备源约 30 秒）。等半分钟。

**商品那块显示"未登录"？**
点击商品面板的「登录抖音」按钮，在专用窗口中完成登录即可。程序会自动保存并启用登录态，不影响其他功能。

**商品那块显示"本场暂无商品讲解数据"？**
这个直播间没挂小黄车（不带货），或还没开始讲解商品。

**弹幕量很少？**
房间本身冷清就会这样。进场在涨、在线有数，就说明采集是正常的。

**换了直播间数据没了？**
没丢，切房间会自动开新场次归档。点「历史场次」能看到之前的。
